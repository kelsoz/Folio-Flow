# Folio Flow 0.4.1

## 中文

- 统一导出、压缩、保存确认、设置与关于弹窗：不透明背景，精简说明，按分组区分标签与控件间距，并校准文字对齐。
- 图片导出倍率与纯图 PDF 清晰度右侧显示当前页实际输出像素，切换选项同步更新。
- 原文件夹按钮展开文件菜单，收纳打开、保存、另存为、导出、设置与退出；移除中间三点菜单。保留第一组工具栏原宽度、文件名截断、页码及撤销重做。
- 设置收纳亮暗外观、阅读位置记忆、清除记录、默认 PDF 阅读器及关于入口；清除记录在左下角标红。关于显示当前版本，检查更新打开 GitHub Releases。
- 默认记忆最多 100 份 PDF 的阅读页码、页内纵向位置、缩放与单双页布局；仅在关闭/切换文档或正常退出时保存，阅读操作与切换视图不写入记录。记录保存在本机用户配置目录，不修改 PDF；文件被替换或存在未保存页面编辑时不覆盖旧记录。
- 默认阅读器入口注册当前程序能力，通过 Windows Shell 打开系统默认应用设置，由用户确认默认选择。
- 设置使用官方圆形齿轮图标；导出改为方框向外箭头，便于与保存区分。

## English

- Unified export, compression, unsaved-change, settings and about dialogs with opaque backgrounds, concise copy, grouped spacing and corrected text alignment.
- Image export scale and image-PDF resolution show the current page’s actual output pixel dimensions.
- The folder button opens a file menu for Open, Save, Save As, Export, Settings and Exit. Removed the middle ellipsis menu while preserving the original file-toolbar width, truncated filename, page field, undo and redo.
- Settings groups appearance, reading-position memory, record clearing, default-PDF setup and About. The clear-records action is red in the footer. About displays the build version; update checking opens GitHub Releases.
- Locally remembers up to 100 PDFs: page, vertical page offset, zoom and single/two-page layout. Records are saved only when closing/switching documents or exiting normally. Reading and view switching do not write records. PDFs remain untouched; replaced files and unsaved page edits do not overwrite existing records.
- Default-PDF setup registers the running app and opens Windows default-app settings through the Shell for user confirmation.
- Uses the official settings gear and an outward-arrow export icon to distinguish export from saving.
