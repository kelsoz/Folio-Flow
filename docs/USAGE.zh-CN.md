# Folio Flow 使用说明

直接运行 `Folio Flow.exe`。移动程序时，请将整个 `Folio Flow` 文件夹一起移动，保留同目录下的 `pdfium.dll`。

## 阅读与编辑

打开 PDF 后可连续滚动、搜索文字、复制文本、调整缩放、切换明暗主题。左侧“页面”用于缩略图导航，“页面编排”用于整理。

中间工具栏可切换“单页”“双页”和“页面编排”。双页按 1–2、3–4 并排，奇数末页居中。各视图与侧栏均支持平滑滚动及上下边界回弹。切换三种视图时，同一张页面会平滑移动、缩放到新位置；快速反向切换从当前画面接续。整理视图中选中的页面会在返回阅读时展开。

单页或双页阅读时，点击左侧页面缩略图会在固定 420 毫秒内平滑滚动到目标页，跨很多页也不会延长时间。再次点击可从当前位置转向另一页，滚轮、滚动条、缩放和文字选择能直接接管。整理视图手动展开侧栏后的缩略图点击，仍保持返回原阅读布局并使用页面匹配过渡。

按 Tab 进入沉浸模式，隐藏所有浮动工具栏、侧栏和搜索栏，阅读或整理内容铺满窗口；再次按 Tab 恢复原来的界面。两次切换都会显示底部提示。弹出对话框时 Tab 保留为焦点切换键。

将一个图片或 PDF 拖到“页面”导航栏或页面编排视图，光标处会显示插入位置，周围页面让位；靠近上下边缘会自动滚动。松手后图片生成一页，PDF 插入全部页面，每次拖入一个文件。拖到阅读画布其它位置的 PDF 则作为另一份文档打开。

支持 PNG、JPG、WebP、BMP、GIF、TIFF。图片按 72 DPI 导入，处理 EXIF 方向，透明部分铺白；GIF/TIFF 使用首幅图像。来源文件移走后，已导入页面仍可撤销、重做和保存。

- Ctrl+Z：撤销；Ctrl+Y / Ctrl+Shift+Z：重做。
- Ctrl+S：保存；Ctrl+Shift+S：另存为。
- Ctrl+F：查找；Ctrl+P：打印当前内容，包含尚未保存的编辑。
- Ctrl+O：打开文档；Ctrl+B：侧栏；Ctrl+E：导出。

文件名前的圆点表示尚未保存。关闭或切换文档时，可选择保存、不保存或取消；保存失败会保留当前编辑结果。

## 文件菜单与设置

最左工具栏的文件夹按钮展开文件菜单：打开、保存、另存为、导出、设置和退出。原工具栏宽度、文件名截断、页码及撤销重做保持不变；小窗口将文件入口收纳到紧凑工具栏。右侧齿轮打开设置，亮暗外观更改即时生效。

“记住阅读位置”默认开启，重新打开同一路径且未被替换的 PDF 时，恢复页内位置、缩放和单双页布局。仅在关闭/切换文档或正常退出程序时保存一次，阅读与切换视图不写入记录；未保存的页面编辑不会覆盖已有阅读记录。命令行显式指定页码或缩放时优先使用命令行参数。

偏好与最多 100 份文件的阅读记录保存在 `%APPDATA%/Folio Flow/`，不写入 PDF。关闭开关停止记录和恢复；“清除阅读记录”清空历史，当前文档在重新打开或重新启用记忆前不会再次记录。文件移动、改名或内容改变后不保证恢复；不同窗口同时写入同一文件时以最后一次记录为准。

“设为默认…”注册当前程序的 PDF 能力并打开 Windows 默认应用设置，由用户完成确认，不修改受保护的默认选择。先把程序放在长期使用的位置，再设置默认；之后移动程序应重新设置。系统入口遵循 [Windows 默认应用设置文档](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings)。

“关于”显示当前构建版本、项目主页和更新说明；“检查更新”打开 GitHub 发布页面，暂不自动比较或下载安装版本。

## 中键平移

单页、双页阅读时，按住鼠标中键（滚轮按键）拖动即可平移，内容跟着鼠标移动，松开停止。任意缩放比例均可操作，但只有超出视口、有可滚动空间的方向会移动：适合宽度时通常只能上下移动，放大后可横向和纵向移动，到文档边缘停止。拖动会直接接管当前动画，且不会选中文字或打开链接。

## 导出和压缩

导出支持 Markdown、JPG、PNG。图片尺寸与纯图压缩清晰度的标题右侧显示当前页实际输出像素；不同尺寸页面按各自尺寸输出。图片以 72 DPI 为 1×，可选择 1.5×、2×、3×；每页单独保存到新的文件夹。

压缩支持无损整理与纯图 PDF。纯图方式提供清晰度、JPEG 质量及抽样体积预估，仅保留页面外观，移除文字、链接、书签和表单等数据，保存为副本。预估体积可能与实际明显不同，无损整理也不保证一定缩小文件。

## 当前边界

不支持密码 PDF。重排、删除和插页采用 PDFium 页面导入，复杂文档的签名、表单、附件、命名目的地和物理书签结构保全仍有限制，适合先另存编辑副本。

自动化覆盖编辑、保存失败恢复、打印、图片导出和纯图 PDF 等流程；真实系统拖放、DPI 切换和动画手感仍需实机确认，未宣称所有 PDF 场景均已验收。
